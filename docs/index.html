ENURI

문제의식

최초의 멀티모달 협상 벤치마크

기존 협상 벤치마크는 전부 텍스트만 다룹니다. 시장 구조가 아무리 복잡해져도(1:1, 1:N, N:N), 이미지를 실제로 쓰는 협상 벤치마크는 지금까지 없었습니다.

NegotiationArena, TERMS-Bench, 그리고 시장 구조 면에서 가장 정교한 AgenticPay(1:1부터 다대다 시장까지 110개 이상 태스크)까지 — 전부 LLM이 협상 대화를 직접 만들지만, 이미지를 입력으로 받는 벤치마크는 하나도 없습니다. ENURI는 저희가 확인한 한 협상 대화 생성 + 시각 증거 입력을 결합한 최초의 벤치마크입니다.

ENURI는 결함을 이미지 생성 단계부터 보이는 정도(Obvious/Subtle)와 겉보기-실제 일치 여부(Aligned/Misaligned) 두 축으로 통제합니다. 그 결과 “발견했는가(Detection)”와 “제대로 값을 매겼는가(Valuation)”를 완전히 분리해서 잴 수 있습니다.

시스템 개요

전체 구조 한눈에 보기

데이터셋 → 협상 환경(커널) → 에피소드 기록 → 9개 지표, 네 단계로 이어집니다.

평가 대상 agent(한 번에 하나)가 고정 공식으로 반응하는 counterpart와 최대 K턴 협상합니다. counterpart의 매턴 수락 확률은 “일반적인 협상 요소 + 증거 항(진짜 결함을 인용했는가 × 사분면 가중치)” 공식으로 계산되고, 끝난 에피소드는 전부 기록되어 9개 지표(SE⁺, AGR⁺, CSE⁺, CritViol%, 인용 정확도/재현율, 환각률, 활용도, 보정 ρ)로 요약됩니다.

데이터셋 구축

결함은 어떻게 만들어지는가

실제 중고거래 사진에 결함을 합성하고, 생성 모델 자신이 다시 검수합니다.

CraigslistBargain 실제 매물 사진 636장 중 결함 언급이 없는 것만 골라, 사분면(Obvious/Subtle × Aligned/Misaligned)을 먼저 정하고 그 조건에 맞는 결함을 사진에 합성합니다. 생성과 동시에 만들어진 설명(ground truth)은 검수 단계에서는 숨깁니다 — 같은 모델에게 편집된 사진만 다시 보여주고 “여기 결함이 보이나요”라고 blind로 재검증해서, 통과 못 하면 재생성합니다.

작동 방식

협상은 어떻게 진행되는가

평가 대상은 단 하나 — Buyer 또는 Seller 역할을 맡은 LLM/VLM 에이전트뿐입니다. 상대방(counterpart)은 고정된 규칙에 따라 반응하는 시뮬레이션입니다.

AgentCounterpart
Offer: $80 — 패널에서 균열을 발견해서, 이 이상은 어렵습니다.cites: crack
$80은 너무 낮습니다 — $95는 어떻습니까?
균열을 감안해서 $85까지 맞춰드리겠습니다.cites: crack
좋습니다 — $85로 합의하겠습니다.ACCEPT

에이전트는 매 라운드 아이템 사진과 자신의 예약가격, 지금까지의 대화를 보고 OFFER / ACCEPT / REJECT를 결정합니다. 결함을 언급하려면 cites 필드에 어떤 종류인지 구조화된 형태로 함께 적어야 합니다.

상대방(counterpart)은 LLM이 자유롭게 판단하는 게 아니라, 정해진 공식으로 수락 확률을 계산합니다 — 가격이 얼마나 유리한지, 남은 시간, 그리고 에이전트가 진짜 결함을 인용했는지가 이 공식에 들어갑니다. 지어낸 결함은 0점 처리됩니다.

같은 인용도, 두 번 채점됩니다

결함을 언급할 때마다 두 가지를 순서대로 확인합니다 — 이 둘은 완전히 별개의 점수입니다.

진짜로 뭔가를 발견했는가?

Yes — 실제로 있던 결함 No — 없거나 지어낸 것 → DETECTION 실패

가격을 그만큼 제대로 반영했는가?

Yes — 실제 가치만큼 가격이 움직임 No — 너무 적게/많이, 또는 무반응
→ 발견(Detection)과 가격 반영(Valuation)은 별개로 채점됩니다. 최종 협상 가격 하나만 보지 않는 이유입니다.
결함 설계

2×2 evidence-difficulty grid

모든 결함은 생성 시점에 두 축으로 통제됩니다. 이 라벨은 에이전트에게 절대 공개되지 않습니다.

AlignedMisaligned
ObviousOA · 0.30OM · 0.15
SubtleSA · 0.90SM · 1.20

이 숫자는 “가격을 얼마나 깎아야 하는가”가 아니라 “이 인용이 얼마나 진짜 의미 있는 신호인가”를 나타내는 가중치입니다. 뻔히 보이는 걸 말하면 약한 신호(0.30), 안 보이는데 실제로 심각한 문제까지 짚으면 가장 강한 신호(1.20)로 취급됩니다.

특히 Subtle-Misaligned는 발견도 어렵고 판단도 어려운 유일한 칸 — 가장 까다로운 케이스로 설계했습니다.

핵심 발견

16개 에이전트, 6,400개 협상

13개 LLM/VLM과 3개 규칙 기반 baseline을 4가지 가격 기준 아래 각각 100회씩 실험했습니다.

SE⁺?

Surplus Extracted — 협상 가능한 가격 구간(ZOPA) 중 이 agent가 실제로 챙긴 이익의 비율이다. 1에 가까울수록 최대한 유리하게 협상했다는 뜻이고, 0이면 거의 못 챙겼다는 뜻이다. 아래 그림들의 기본 성적표라고 보면 된다.

EXHIBIT 01헤드라인 순위
읽는 법: 막대 길이 = SE⁺ 점수, 검은 선 = 95% 신뢰구간(길수록 불확실), 색 = 모델 등급.

SE⁺ 기준, 상위권은 거의 동률

ZOPA 대비 실제로 확보한 협상 이익(SE⁺)으로 줄을 세우면 Claude Opus 4.6·Grok 4.5·Kimi K3가 공동 선두이고, 상위 9개 agent의 신뢰구간은 겹칩니다.

GPT-4o-mini: SE⁺ = 0.04 — 사실상 무작위 가격 책정 수준
EXHIBIT 02핵심 발견
읽는 법: 두 그림 다 같은 2×2 격자(세로=눈에 띄는 정도, 가로=겉보기-실제 일치 여부). 색이 진하고 숫자가 클수록 그 능력이 좋다는 뜻. 왼쪽=발견율, 오른쪽=가격 반영 정확도.

발견과 가격 반영은 다른 능력이다

같은 2×2 격자에 Detection(발견율)과 Grounding(가격 반영 정확도)을 나란히 놓으면, 두 능력이 완전히 다른 축에서 무너집니다.

Detection: Obvious 0.56 → Subtle 0.28 (13/13 agent 유의미)
Grounding: 3칸 0.92–1.00 vs Subtle-Misaligned만 0.73
EXHIBIT 03확대
읽는 법: 점 하나 = agent 한 명, 가로선 = 95% 신뢰구간. 점이 0보다 왼쪽에 있으면 “실제로 더 심각한데도 가격을 덜 깎았다”는 뜻(과소반영). 오른쪽 그래프(Subtle)에서 점 대부분이 왼쪽에 몰려있는 게 핵심.

가격 반영 실패는 한 칸에 집중된다

Obvious 조건에선 Aligned/Misaligned 사이 의미 있는 가격 차이가 없습니다 — 문제는 Subtle, 그중에서도 Misaligned입니다.

Subtle-Misaligned: 10/11 agent가 유의미하게 실제 가치보다 낮게 책정 (다중비교 보정 후)
EXHIBIT 04agent별 실패 지점
읽는 법: agent 한 명당 막대 하나, 100%를 4가지 색으로 분해. 회색=아예 언급 안 함, 주황=딴 걸 언급, 파랑=맞게 언급했지만 형식이 안 맞음, 초록=완벽하게 잡음. 초록이 길수록 잘한 것.

같은 실패도, 이유는 제각각

가장 어려운 Subtle-Misaligned 칸에서 각 agent가 정확히 어디서 놓치는지 분해했습니다.

Gemini 3.1 Pro 35% 클린 히트, Claude Opus 4.6 0%(41%는 딴 걸 인용), Gemma-4-31B는 81% 무응답
